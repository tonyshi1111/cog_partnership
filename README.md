# Cognition Partnership Strategy

A self-proposed thesis on the Head of Partnership role at Cognition AI.

Static HTML/CSS/JS — no build step. Open `index.html` directly or serve locally:

```
python3 -m http.server 8080
```

## Structure

| File | What it is |
|---|---|
| `index.html` | Landing page · framework intro · SI-boundary callout |
| `personas.html` | 14-card persona index grid |
| `personas/*.html` | 14 detail pages (Profile · named target partners · 2x2 quadrant · value prop · deal shape · pipeline notes · recent signals) |
| `competitive.html` | Past-3-month positioning vs. Cursor / Claude Code / Copilot + secondary comparators |
| `prioritization.html` | Bubble chart of synergy × ease × market across all 14 personas |
| `pipeline.html` | Inbound + outbound flowcharts · RACI matrix · SI complementarity · worked examples |
| `assets/citations.json` | 48 sourced references (44 dated Feb 2026+; 4 pre-Feb foundational) |
| `styles.css` | Design language: clean, dense, low-chrome, single warm-rust accent |
| `script.js` | Citation footnote resolver |

## Methodology

14 personas, holistically ranked by composite of synergy + ease + market (equal-weighted). Past-3-months-only sourcing rule. Tegus-informed taxonomy: dropped AI/ML infra; added Enterprise Compliance / GRC; split CI/CD out of Dev Infra.
