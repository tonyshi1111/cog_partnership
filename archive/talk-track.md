Infosys + Cognizant embed Devin into how the world's largest IT services firms deliver code to Fortune 500s. **Multi-billion-dollar TAM that Cursor structurally cannot access** — wrong motion, wrong buyer, wrong pricing model.

**VOICEOVER:**
> So what is the actually defensible moat? Three things compounding. One — enterprise distribution and trust we got there first on. Goldman, Infosys, Cognizant, Dell aren't switching to Cursor for ticket-driven async work because nobody else has built the audit logs, the SSO, the sandbox isolation, the services partnerships for that buyer. Two years of lead time in enterprise procurement is real. Two — the async UX itself is harder than it looks. Cursor's loop is "human types, AI completes" — easy to evaluate, easy to iterate. Devin's loop is "human writes ticket, comes back in six hours, evaluates a PR." That requires the agent to be right about scoping, planning, self-correction, and knowing when to ask for help — and it requires a UI where a human can audit hours of work quickly. - **The bull case requirement, one line:** Sustained capability lead on the async loop (planning · self-review · computer use) **AND** converting that lead into stickier enterprise deals before the model layer catches up.

**VOICEOVER:**
> And I want to be honest about the risk before I get to the partnership thesis, because credibility matters. The wedge depends on async agents being good enough to leave alone. If that capability ends up commoditized at the model layer — and Anthropic, OpenAI, and Google are all racing toward that — then Devin's premium collapses and the moat is just the enterprise relationships. Those are valuable, but not 25-billion-dollar valuable on their own. So the bull case requires Cognition to keep a sustained capability lead on the async loop specifically — the planning, the self-review, the desktop computer use — *and* to keep converting that lead into stickier enterprise deals before the model layer catches up. That's the strategic constraint everything else has to feed.
