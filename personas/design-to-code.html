Profile

Design artifacts (Figma frames, Storybook component definitions, Framer layouts) are increasingly the spec from which production code is generated. The design-to-code partnership shape is real: design → AI agent extracts component hierarchy, tokens, layout → agent writes React / Tailwind / Vue / Swift code that matches. Cognition has shipped Figma MCP (Devin reads Figma files and produces React / Tailwind code, opens browser to verify), but Codex + Claude Code + Cursor all have equivalent Figma integrations. This is table stakes, not a moat.

Partnership opportunity here is exclusive deeper coupling (Figma Make co-features, joint Config conference presence) rather than basic MCP integration.
