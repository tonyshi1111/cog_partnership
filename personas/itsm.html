Profile

Enterprise IT and service-management platforms are repositioning as the AI workforce orchestration layer — ServiceNow's Knowledge 2026 framing was an "autonomous workforce." These platforms are where tickets live, where SLAs are tracked, and increasingly where AI agents are dispatched to do work.

They are building their own coordination agents (ServiceNow Build Agent, Atlassian Rovo) but those agents orchestrate and respond rather than write code. The partnership wedge: when an enterprise ticket implies real engineering work (build this integration, fix this internal tool, refactor this legacy report), the ITSM platform invokes Devin as the execution agent.

ServiceNow alone has 8,000+ enterprise customers — distribution at this scale changes the deal economics for Cognition versus most other personas.

Where Cognition wins (2×2)

X-axis: Code-engagement depth (does the agent actually write and merge production code, or only orchestrate / respond?). Y-axis: Enterprise workflow surface integration (lives natively in the ticket platform vs. requires switching tools). Cognition portfolio lands top-right via the Windsurf-in-ServiceNow foundation plus Devin async invocation. ServiceNow Build Agent has surface integration but limited code depth; Cursor + Claude have code depth but lack async ticket-triggered invocation.

Value proposition

Cognition → ServiceNow

Devin is the engineering execution layer their orchestrator agents need. ServiceNow Build Agent + Devin = first true ticket-to-merged-PR autonomous loop. Strengthens ServiceNow's "autonomous workforce" narrative with verifiable code output.

ServiceNow → Cognition

Enterprise distribution at scale — ServiceNow alone serves 8,000+ enterprises. ServiceNow Store as the AI agent marketplace gives Devin a credentialed enterprise listing. MDF funding underwrites co-marketing costs.
