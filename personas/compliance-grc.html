Profile

Compliance is the recurring enterprise rollout blocker for Devin per the Tegus interviews — Wolters Kluwer, Publicis Sapient, and Curai Health all flagged compliance / security as the make-or-break enterprise consideration. The GRC category is in the middle of a major AI-readiness shift in 2026: Vanta AI Agent 2.0 shipped Jan 2026 (15,000 customers); Vanta, Drata, and Secureframe all shipped MCP servers.

The partnership opportunity here is dual-purpose: (a) close the compliance-evidence gap that blocks Devin enterprise rollouts by integrating with GRC platforms customers already trust, and (b) make Devin the agent-of-record for compliance-evidence-collection work itself (security questionnaires, policy drafting, control documentation).

Where Cognition wins (2×2)

X-axis: Coverage of full compliance lifecycle (evidence collection → policy drafting → questionnaire filling → control documentation → audit defense). Y-axis: Enterprise trust + auditor acceptability. Vanta AI Agent 2.0 alone covers questionnaires / policies; Devin layer adds codebase-derived evidence (e.g., "Devin generated this control test from your repo, here's the audit trail").

Value proposition

Cognition → GRC partner

Codebase-derived compliance evidence (Devin can audit code for compliance with control X, generate evidence artifacts auditors accept). Closes the loop between "what is the code doing" and "what does the compliance dashboard claim." Differentiates the GRC vendor as the compliance platform that actually checks code, not just configuration.

GRC partner → Cognition

Distribution to compliance-conscious enterprises (the customer segment most likely to be currently blocked on Devin rollouts). Enterprise trust signal — "Vanta-certified AI agent" or "Drata-integrated" is enterprise procurement gold.

Deal shape

  • Tier 1 — MCP integration
    Devin uses Vanta / Drata / Secureframe MCP for compliance context + marketplace listing on the GRC vendor's integration directory.
  • Tier 2 — Co-built compliance use case
    Devin generates SOC 2 / ISO 27001 / HIPAA evidence from codebase; vendor surfaces this in dashboard + joint case study at flagship compliance-conscious customer.
  • Tier 3 — Code-aware compliance SKU
    GRC vendor sells "code-aware compliance" as a premium SKU with Devin underneath; revenue share; co-engineered audit-trail features ensuring Devin actions are auditor-acceptable.
