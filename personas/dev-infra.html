Profile

Modern dev infrastructure — source control alternatives to GitHub, deployment platforms, edge runtime, build / CI — is the second-most natural integration surface for coding agents after workflow tools. The defining 2026 dynamic: dev infra companies are themselves becoming sophisticated agentic-coding adopters. Cloudflare ran 131,246 AI code reviews in 30 days (March–April 2026) using OpenCode + GitLab CI. Vercel sees 30% of all deployments now agent-initiated, with Claude Code at 75% of that volume.

The partnership opportunity is twofold: (a) get Devin embedded as the agent of choice for their dev infra workflows, and (b) leverage their AI-agent infrastructure (Vercel AI SDK, Cloudflare Workers, Agent Builder) as deployment targets for Devin's output.
