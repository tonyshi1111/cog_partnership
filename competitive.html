Defensible territory map

After three months of evidence, Cognition's defensible territory in the agent stack is the audit-grade async cloud-execution lane PLUS the supervised IDE lane via Windsurf — i.e., the only vendor offering both surfaces under one portfolio. Specific positioning:

Where Cognition uniquely wins

Long-horizon enterprise migrations (Devin's COBOL / Fortune 500 case studies), Slack-native autonomous task delegation, audit-grade execution for regulated industries (FSI, healthcare, gov), and design-time IDE + async cloud as a coordinated dual-product story.

Where Cursor wins

Daily-driver IDE for mixed engineering teams; AWS Agent Plugins early-mover advantage; SpaceX compute moat.

Where Claude Code wins

Senior / platform engineer favorite for complex refactors; Anthropic Partner Network distribution; SAP Joule + PwC enterprise lock-in.

Where Copilot wins

GitHub-native incumbent advantage; Microsoft enterprise procurement bundles; Snyk Studio + ServiceNow Build Agent integrations.

Where OpenHands wins

Open-source / max-control buyers willing to self-host; non-Cognition enterprise budgets (AMD, Apple, Google, Amazon adopting).
